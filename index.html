How to use this library

Find the category for what you want, or type a word in the search box above. The search looks at every file's name, category, format, and keywords, and it filters as you type.

Every file shows its name, its format, its category, and its version, revision date, and author where the file name carries them. File names carry a version stamp, like v2.0-20261116-2218-AB9MZ, which reads as version 2.0, revised 16 November 2026 at 22:18 Central, by AB9MZ. The stamp tells you at a glance whether the file you found is the current one.

Two kinds of file label appear on this page:

  • A download link. Tap the file name to download it.
  • Superseded by this page. The old text index is no longer updated, because this page is the index now.

To come back to the group, use the Back to Visually Inconvenienced Hams link at the top or the bottom of this page. Inside Facebook's own browser that link becomes a close button instead.

AB9MZ Master Field Reference — Edition 2.0

Gregory Rosenberg AB9MZ's field reference, 22 sections, 112 pages, in large print (22 point text, 28 point headings). Every section is here in three formats: a large-print PDF, a Word document, and a tagged PDF that screen readers navigate by heading. The collection has its own home page, with an offline section selector that builds a custom edition from the sections you pick: AB9MZ Master Field Reference home page.

Braille and plain-text editions of the whole book and every section are also available, in the field-reference repository: Braille files (.brf, contracted UEB grade 2) and plain-text files (.txt). The full book and every section below also carry their own Braille download link, next to the main download link, so you can grab the .brf file for just the part you want without opening the folder.

              About this library

              This page replaces the group's text document index. Facebook does not let a group organize its Files into folders, and its phone app lists files newest first with no sort control at all, so the group keeps its library here instead, where the files sit in real categories, the search box finds them, and the sort order stays the way you set it.

              Most files on this page are the group's own documents, or public-domain material such as the Technician question pool. Every file on this page has a download link, except the document index itself, which this page replaces. Manufacturer radio manuals are not part of this library; they live on the group's amateur radio manuals page, which links to the makers' own sites.

              If a link on this page stops working, or if you would like a document added to the library, post in the Visually Inconvenienced Hams group and say which file it is. A member who wants to share a document sends it to an admin, and an admin adds it here.

              First edition — 16 November 2026. 77 documents listed: the AB9MZ Master Field Reference collection (71 files), the contest schedule, the document index, the Technician question pool in plain text and Braille, the Tonne filter article, and the blind-population reference.
