Find a file

Find the topic for what you want. Each topic starts closed, so you see the list of topics first. Pick a topic heading below to open it. Pick it again to close it.

Or type a word in the search box above. The search looks at each file's name, topic, format, and key words. It narrows the list as you type.

One button just below this guide opens every section at once. Once they are all open, the same button closes them all.

Each file shows its name, its format, and its topic. It also shows its version, its date, and its author, when the file name holds them. File names hold a version stamp, like v2.0-20261116-2218-AB9MZ. That stamp means version 2.0, changed 16 November 2026 at 22:18 Central, by AB9MZ. The stamp tells you at a glance if the file you found is the newest one.

The three buttons

Each file has up to three buttons:

  • Open. Opens the file.
  • Listen. Reads the file out loud with your device's own voice. Some files do not have this button yet.
  • Braille. Downloads the file in Braille. Some files do not have this button yet.
  • Superseded by this page. The old text index is no longer updated, because this page is the index now.

Below the buttons is the direct link to the file. It is there as a backup, in case a button does not work.

On Facebook

The files used to live in the group's Facebook Files section. The list had grown long and hard to search, most of all with a screen reader. So they moved here. Nothing was lost — every file that was in Files is in the library.

The group's Facebook Files section still holds the contest schedule and the full list of links, in two formats: a PDF with buttons and a plain text file. The contest schedule is in the library too.

When you tap a file in the group's Files on your phone, Facebook shows a small menu with two choices: See Original Post and View File. Tap View File to open the file. See Original Post just takes you to the post that announced the file.

To go back to the group, use the Back link at the top or the bottom of this page. Inside Facebook's own browser, that link is a close button instead.

If you have any trouble finding something, ask in the group or at the Saturday night net and we will help you find it.

This is Gregory Rosenberg AB9MZ's field reference. It has 22 parts and 112 pages, in large print (22 point text, 28 point headings). Each part is here in three forms: a large-print PDF, a Word file, and a tagged PDF that screen readers can move through by heading. The book has its own home page too. There you can pick parts and build your own edition to use offline: AB9MZ Master Field Reference home page.

Braille and plain-text copies of the whole book and each part are also in the field-reference file store: Braille files (.brf, contracted UEB grade 2) and plain-text files (.txt). The full book and each part below also have their own Braille button, next to the Open button, so you can get the .brf file for just the part you want.

                Files without a Listen or Braille button

                Most files on this page have all three buttons: Open, Listen, and Braille. A few do not. Here is why, file by file.

                • The complete kit zip file has no Listen or Braille button. It is a zip file full of other files, not a document to read. The files inside it have their own buttons.
                • The old document index has no Open, Listen, or Braille button. This page takes its place. It stays listed so people can still find it.
                • The Tonne filter article has no Listen or Braille button. It lives on the author's own web site, not here. This page links to his copy.
                • The read-me file and the contest schedule have no Braille button yet. Both are plain text already. The schedule changes each day, so a Braille copy would go out of date fast.
